# aicohosts.ai

Static coming-soon page for aicohosts.ai.

- `index.html` is the whole site. The host photos are embedded in it, so it deploys as a single file.
- `img/` holds the same photos as separate files, for editing or reuse.

No build step. Any static host (Netlify, Cloudflare Pages, GitHub Pages) can serve the repo root.
